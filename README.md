## 🌟 About This Project

This repository contains the source code for my personal portfolio website. It was designed from the ground up using **Next.js 15 (App Router)** and **TypeScript**, prioritizing a clean UI/UX, fast loading speeds, and robust structural architecture. The project leverages **Tailwind CSS** and **HeroUI** for sleek, responsive styling, and features dynamic routing for individual project deep-dives.

## 🛠️ Tech Stack

- **Framework:** [Next.js (App Router)](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Library:** [HeroUI](https://heroui.com/)
- **Form Handling:** [Web3Forms](https://web3forms.com/) (Serverless email routing)
- **Deployment:** [Vercel](https://vercel.com/)

## ✨ Key Features

- **Dynamic Project Routing:** Utilizes Next.js `generateStaticParams` to pre-render dynamic project detail pages (`/projects/[id]`) for instant load times and SEO optimization.
- **Modern UI Architecture:** Component-driven design separating concerns across `Hero`, `About`, `Skills`, `Projects`, and `Contact` sections.
- **Fully Responsive:** Fluid layouts that adapt perfectly to mobile, tablet, and desktop screens.
- **Functional Contact Form:** Real-time form submissions routed directly to email without requiring a dedicated backend server.
- **Optimized Assets:** Next.js `<Image>` component used for automatic image optimization, lazy loading, and layout shift prevention.

## 🚀 Getting Started (Local Development)

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sohan3n/portfolio.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```
3. **Install the dependencies:**
   ```bash
   npm install
   ```
4. **Run the development server:**
   ```bash
   npm run dev
   ```
5. **Open the app:**
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

## 📁 Project Structure

```text

│   ├── components/         # Reusable UI components (Hero, Skills, etc.)
```
